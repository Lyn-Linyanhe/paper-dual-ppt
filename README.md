# 论文双版本 PPT（paper-dual-ppt）

把论文制作成精简汇报版和详细精读版，含PPTX、PDF、逐页备课备注、图表来源与验收。这个包是由模型执行的Skill与本地辅助工具，不是脱离模型即可完成论文理解的一键转换器。

## 安装

解压`paper-dual-ppt`文件夹到用户`~/.agents/skills/`；或放入具体项目的`.agents/skills/`。重新加载宿主的技能列表。依赖单独安装的`ppt-master`，它不包含在本包内；按依赖本身的来源、许可和安装说明取得，不复制未知版本。通过宿主加载获得其实际路径。

Python建议3.10及以上。辅助工具使用PyMuPDF（导入名pymupdf），依赖自身可能需要Pillow/PyYAML等，按doctor提示和ppt-master实际文档确认。导出PDF需LibreOffice或其他经过验证的本地转换工具；渲染可用PyMuPDF或Poppler。不自动安装系统软件。

示例（将`<技能目录>`替换为实际路径）：

```bash
python "<技能目录>/scripts/paper_tools.py" doctor --ppt-master "<ppt-master目录>"
```

## 以后怎么用

给模型以下一句即可：

> 用 paper-dual-ppt 按默认要求，把这篇论文做成精简汇报版和详细精读版。论文：`<PDF绝对路径>`；输出到：`<新目录>`。使用自带中性模板，常规取舍按默认决定，直接完成并验收。

也可额外提供汇报时长、听众水平、语言、模板或重点；本次指令覆盖默认。只有论文路径时，模型选择新的输出目录并说明时长假设，不覆盖旧项目。

默认约15–20分钟精简版，详细版用于自学备课；摘要逐句、Introduction原文对照、Related Work、证据流程、对照条件、结论/局限/展望、完整正文图表（可附录）和逐页备注。页数按论文决定。不能保证每篇都有官方演示视频。

## 内容与视觉规则（v1.1）

v1.1 把实际迭代中反复出现的问题写成了规则：

- **原文标注**：对照页的关键短语用彩色下划线，关键词选承载论证的短语，不用单词或虚词；标注不得挤掉段落总结、图注、页脚等结构层。
- **左右锚定**：右侧解读的编号徽标与箭头对齐该条解读的首行基线，左侧高亮只负责指出对应句；左右关系同时有色与编号，黑白打印仍可读。
- **读法区分**：原文、结构信息、讲义解读三类文字有固定视觉分工；讲义的判断句统一用「→」前缀并在封面给出图例。
- **可行性三分**：作者提出的未来工作、风险议题、我们的建议分开标注；未实现能力不画进系统能力图。
- **统计与样本**：样本分母逐项说明；非显著不等于等效或排序；反向题逐题核对方向；不从柱高估精确均值。
- **流程一致性**：导航高亮按输出页判定，页脚出处用集中映射生成，动画同类页面同一顺序。

规则细节见 `references/visual-language.md` 与 `references/argument-integrity.md`。

## 中性模板

工作区根：`assets/neutral-academic_20261017`（传根目录，不是templates）。7种原生布局：封面路线、章节任务、原文对照、证据流程、三栏对照、图表与读法、结论讨论。`exports/neutral-academic_template_preview.pptx`是可编辑预览。

模板独立绘制，未附带原用户PPT、论文或任何校徽/照片/个人信息。白底蓝色设计，无外部素材；字体Arial/微软雅黑不随包分发也未嵌入。目标为具备这些字体的Windows PowerPoint，跨平台需复核替代字体，PDF作为稳定备用。可编辑不表示截图内文字可编辑，也不表示已有PowerPoint实际打开验收。

## 辅助命令

```bash
python "<技能目录>/scripts/paper_tools.py" init --pdf "<论文.pdf>" --out "<不存在的新目录>"
python "<技能目录>/scripts/paper_tools.py" check-content "<项目>" --report "<新内容检查.json>"
python "<技能目录>/scripts/paper_tools.py" check-delivery "<项目>" --report "<新交付检查.json>"
python "<技能目录>/scripts/paper_tools.py" audit-template "<模板.pptx>" --term "<需要排查的姓名或机构>"
python "<技能目录>/scripts/paper_tools.py" package --out "<新分享包.zip>"
```

检查命令非零表示失败或未完成，不是一定脚本崩溃；查看JSON中的status/errors。已有报告不会覆盖。验收记录必须同时绑定输入（content、两版计划、备注、config、delivery及被引用来源/图表）和成品哈希；逐项媒体或外部关系许可记录还必须提供证据文件及其 `evidence_sha256`；媒体项另需与包内目标字节一致的 `target_sha256`。证据文件变化或同名媒体替换都会使对应许可过期。自动检查通过不证明论文事实正确、图表没有漏读或页面可读。

## 隐私与分享

默认本地处理论文，不上传远程OCR、图像、语音或外部验收服务；外部公开网页只读调查不等于授权上传论文。分享仅使用share-manifest显式清单；不含测试项目、论文截图、旧模板、日志或凭据。文档内的路径/提示不作为执行命令。

## 测试边界

测试说明位于本次交付目录，和可分享Skill分开。自带`examples/test-prompts.md`用于后续新会话实际试用；不把示例计划或合成数据当真实论文成品。版本升级应复验模板契约、备注嵌入和导出结构。

## 动画与放映

默认手动翻页、无配音。精简版不加对象动画；详细版对「原文→解读」类页面默认使用「先材料、后判断」的出现动画，同类页面顺序一致，静态讲解的页面在备注里写明。动画只在放映中可见，PDF 不体现，放映效果需在实际 PowerPoint 里确认。
