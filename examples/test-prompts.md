# 新会话试用提示

这些测试需要在可读取论文的宿主里执行。本包不附带论文，实际路径由使用者提供。不要把提示中的预期结果当已通过。验收项对应 `references/visual-language.md` 与 `references/argument-integrity.md`。

## 1. HCI系统论文

用paper-dual-ppt按默认要求处理`<系统论文.pdf>`，在新目录制作两版。重点讲清形成性研究、系统设计与效果评价分别使用什么证据。直接采用默认值，保护原始文件。

验收：各阶段样本/任务不混合；主观评价不等于客观性能；正文图表全清单；两版结果一致；原文定位与备注齐全。

## 2. 算法论文

把`<算法论文.pdf>`做成默认两版，使用自带中性模板。讲清方法机制、训练/测试数据、基线、指标、实验和消融；汇报按18分钟规划。

验收：不硬造参与者/问卷；区分主实验与消融；公式/假设准确；未报告训练细节不补写；未检出显著性不自动算差异已证明。

## 3. 输入退化

这是一篇扫描论文`<扫描.pdf>`，补充材料目前没有，请做默认两版。

验收：本地OCR/可视核对，记录低文本与缺补充材料影响，不上传；输入不足时明确草稿或阻断状态；不编造数据或官方视频；未检验不声称通过。

## 4. 来源与版本变化

已有项目`<运行目录>`的论文和两版PPT已被我手工修改，请继续修订。

验收：先看当前文件，检测哈希变化；不使用过期审核，不覆盖旧版本；按确切修改范围处理，重新核验受影响内容；旧版日志与交付 JSON 不作为本版证据。

## 5. 对照页标注与对齐

用默认要求处理`<HCI论文.pdf>`，详细版的摘要、Introduction、Related Work 都要按同一规则做原文标注。

验收：关键词是承载论证的短语而非单词；右侧编号与箭头对齐右侧条目首行基线；段落总结、图注、页脚未被标注挤掉；原文与解读有统一的视觉区分；同类页面动画顺序一致。

## 6. 统计与边界复核

把`<含问卷或量表论文.pdf>`做成两版，重点核对样本分母与量表方向。

验收：形成性/正式研究人数不混；反向题方向有标注且与自图一致；非显著没有被写成等效或排序；作者未来工作、风险议题、我们的建议三类分开；未实现能力没有出现在系统能力页。
