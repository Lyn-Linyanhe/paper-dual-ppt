# 论文类型与证据读取

一篇可跨多类；先确认真实类型再选解释结构。无适用元素写不适用及理由。

| 类型 | 重点证据 | 必须防止的误读 |
|---|---|---|
| HCI/系统/设计 | 形成性研究→需求与设计映射→系统→使用/评价；人群、任务、材料、条件、测量和定性分析 | 将形成性研究算进效果样本；把满意度当性能；完整方案比较说成单功能因果 |
| 算法/机器学习 | 问题定义、方法机制、数据切分、基线、训练/推理设置、主要指标、消融、误差/计算成本 | 数据泄漏、测试调参、指标方向误读；把消融当真实场景证明；从图猜精确值 |
| 系统性能 | 工作负载、硬件软件、配置、基线、公平性、吞吐/延迟/资源、扩展性及失效条件 | 不同资源条件直接比较；平均延迟掩盖尾延迟；未测规模外推 |
| 系统综述/元分析 | 数据库、检索式、日期、筛选/纳排、编码、质量评估、综合方法、偏倚与异质性 | 文献数量当效果大小；叙述综述冒充系统综述；检索缺失却补流程图 |
| 理论/数学 | 定义、假设、定理、证明路径、适用域、反例/边界，与既有结果关系 | 示例当证明；忽略假设；强制制造参与者、实验和显著性 |
| 定性/民族志 | 场域、招募/位置性、资料生成、分析/编码、主题与原文证据、反例与可信度 | 主题频率自动推总体比例；编造编码一致性或饱和；引文失去语境 |

Related Work解释“研究脉络—已有做法—尚未解决的问题—本文位置”，不要编造作者没有明确指出的缺口。多个阶段分别登记；样本是否重叠、各项分析分母都需核对。

## 统计边界

识别研究单位/重复测量、检验名称、统计量/自由度、p值、效应量、区间/SE/SD、校正、多重比较、量表正负向和样本分母。原文未给就不补。显著不代表重要，非显著不证明等效；主观感知不等于客观学习或事实准确性；非随机前后变化不能擅称因果。论文自相矛盾时同时记录出处，不自行改数据。

## 退化输入

扫描件需本地OCR或可视阅读；OCR文本标注派生身份。缺页、加密、损坏PDF：保留证据，明确影响范围。没有补充材料时记录已取得的正文覆盖范围。只给摘要不足以称全文精读，两版如只能做初稿应明确标注。中文论文不强制翻成英文原文；没有官方视频不构成任务失败。
