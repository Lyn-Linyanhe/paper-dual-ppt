# 默认偏好（1.1）

用户新要求优先。本文件是偏好，不是对任意论文的事实断言。

- 输出：精简汇报版PPTX/PDF＋详细精读版PPTX/PDF，逐页内嵌备注和旁路Markdown，图表/视频来源、验收和可编辑工程。
- 受众：第一次接触该论文的老师和同学；作者、贡献与证据解释准确，不假设听众懂HCI/生成式AI/统计方法。
- 语言：中文主旨、解释和备注，英文原文/术语/原图保留；关键词补中文。无固定英文比例。
- 精简版：未给时长时按15–20分钟规划，时长包含视频，优先主要研究问题与证据；页数由任务决定。
- 详细版：摘要每句对应原文、编号/颜色和解释（颜色非唯一线索）；Introduction所有论证单元左原文右解释，完整长文可在备注定位；Related Work独立讲解；证据获取与对照条件充分展开；正文编号图表全覆盖（可附录）。
- 摘要可参考1–2页但可读性优先。Introduction按论证单元，不按PDF视觉行断段。无Introduction章节时映射等效动机段，不捏造章节。
- 每图：提出问题、读图顺序、变量/轴/误差线/显著性、支持的主张与边界。多面板放大重要区域；完整原图可在附录查阅。
- 方法：样本或数据来源、条件/任务/流程/测量/分析/证据产出。未报告标注未报告，不补写随机化或预注册。
- 结论/局限/未来方向明确分组；作者未来工作与我们的建议分开，已实现与未实现分开。
- 视频：有官方来源才使用；调查结果是可交付物，视频不是必定存在的承诺。无视频时用原图或关键帧，不冒充可播放素材。
- 视觉：中性白底蓝色、16:9、可编辑正文与示意图；论文截图仍为图片。清晰来源页脚和页码，字号依据投影阅读而定，拆页优于硬缩。全篇视觉语义见 [视觉语言](visual-language.md)。
- 放映：手动翻页，无自动配音。对象动画：精简版默认无；详细版对「原文→解读」类页面默认使用「先材料、后判断」的出现动画，同类页面顺序一致，不得只覆盖前半部分；静态讲解的页面在备注里写明。
- 章节标题：Related Work、Introduction、Method、Discussion 等用论文原语言（通常英文），中文只用于解释，便于对照原文与检索。
- 原文标注：摘要、Introduction、Related Work 等对照页的关键短语使用彩色下划线；关键词选承载论证的短语而非单词或虚词；标注不得挤掉段落总结、图注、页脚等结构层。
- 不上传本地资料；不覆盖旧版本；相对路径与本地处理优先。

## 逐页备注

1. 讲稿/讲解任务和与前后页的衔接。
2. PDF物理页、印刷页（若有）、章节、可检索原文。
3. 必要逐字原文和中文解释；概括不加引号冒充原文。
4. 术语和方法解释、图表读法。
5. 证据边界、容易误读的地方；统计不支持的结论。
6. 有价值的提问（无需每页硬加）。
7. 本页动画/出现顺序（若使用），以及哪一栏是原文、哪一栏是讲义解读。
